# برنامج الوافي 3.0 — حزمة بناء APK

هذه الحزمة مجهزة لرفعها إلى GitHub وتشغيل البناء تلقائيًا عبر GitHub Actions.

## لا تحتاج إلى كتابة كود

1. ارفع جميع محتويات هذه المجلد إلى Repository جديد في GitHub.
2. افتح تبويب **Actions**.
3. اختر **Build Wafi APK**.
4. اضغط **Run workflow**.
5. بعد انتهاء البناء افتح نتيجة التشغيل.
6. من قسم **Artifacts** نزّل **Wafi-APK**.
7. فك الضغط عن Artifact لتحصل على `app-debug.apk`.

## ملاحظات
- هذه نسخة Debug للاختبار على الهاتف.
- لا يوجد فيها مفتاح API للذكاء الاصطناعي.
- المزايا المحلية تعمل دون خدمة AI خارجية.
